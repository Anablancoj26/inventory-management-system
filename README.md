## 🇬🇧 English

### 📌 Project Overview
A robust backend system for inventory management, product stock tracking, and role-based access control (RBAC) supporting Admin and Operator roles. Designed to ensure secure and efficient warehouse operations.

### ✨ Key Features
- **Role-Based Access Control (RBAC):** Distinct permissions for administrators and warehouse operators.
- **Stock Management:** Real-time tracking of product entries, exits, and inventory levels.
- **RESTful API Architecture:** Clean endpoints for resource management.

### 🛠️ Tech Stack
- **Backend:** Python (FastAPI)
- **Database Architecture:** Relational data modeling (SQLite / PostgreSQL ready)
- **Version Control:** Git & GitHub

## 🇪🇸 Español

### 📌 Descripción del Proyecto
Sistema backend robusto para la gestión de inventarios, seguimiento de stock de productos y control de acceso basado en roles (RBAC) para administradores y operadores. Diseñado para garantizar operaciones de almacén seguras y eficientes.

### ✨ Características Principales
- **Control de Acceso por Roles (RBAC):** Permisos diferenciados para administradores y operadores de almacén.
- **Gestión de Stock:** Seguimiento en tiempo real de entradas, salidas y niveles actuales de productos.
- **Arquitectura de API RESTful:** Endpoints limpios para la administración de recursos.

### 🛠️ Tecnologías Utilizadas
- **Backend:** Python (FastAPI)
- **Arquitectura de Base de Datos:** Modelado relacional (Preparado para SQLite / PostgreSQL)
- **Control de Versiones:** Git & GitHub
